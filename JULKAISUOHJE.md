# Autoapuri – verkk julkaisuversio 1.4

Tämä kansio sisältää vain staattisen sivuston julkaisua varten tarvittavat tiedostot:
- `index.html` – Autoapurin käyttöliittymä ja rajattu paikallinen tietopohja
- `privacy.html` – tämän version tietosuoja- ja rajausilmoitus

## Julkaisu maksutta GitHub Pagesilla
1. Kirjaudu tai luo tili osoitteessa https://github.com/ .
2. Luo uusi repository eli projekti. Nimeksi voi laittaa `autoapuri`. Jos haluat osoitteen muotoa `KÄYTTÄJÄ.github.io`, repositoryn nimeksi tulee täsmälleen oma GitHub-käyttäjänimi + `.github.io`.
3. Avaa repositorion **Add file → Upload files** ja lataa tähän kansioon kuuluvat `index.html` ja `privacy.html` (voit jättää tämän README-tiedoston pois).
4. Valitse **Commit changes**.
5. Avaa repositorion **Settings → Pages**. Valitse julkaisutavaksi `Deploy from a branch`, branchiksi `main` ja kansioksi `/(root)`, ja tallenna.
6. GitHub näyttää julkisen osoitteen Pages-asetuksissa. Julkaisu voi kestää muutaman minuutin.
7. Avaa osoite puhelimella ja kokeile kysymyksiä sekä tietosuojalinkkiä.

## Ennen laajempaa markkinointia
- Tämä on rajattu demo, ei vielä tekoälypalvelu eikä kattava automallitietokanta.
- Affiliate-ohjelmia ei ole liitetty eikä seurantalinkkejä ole. Älä lisää affiliate-linkkejä ennen hyväksyntää ohjelmaan ja selkeää kaupallisen yhteyden merkintää.
- Ilmainen GitHub Pages -julkaisu ei vaadi maksullista verkkotunnusta. Älä osta verkkotunnusta tai muuta maksullista palvelua ilman erillistä päätöstä.
- Jos lisätään analytiikka, yhteydenottolomake, kirjautuminen tai tekoäly-API, tietosuoja- ja kustannusarviot on päivitettävä ennen käyttöönottoa.
